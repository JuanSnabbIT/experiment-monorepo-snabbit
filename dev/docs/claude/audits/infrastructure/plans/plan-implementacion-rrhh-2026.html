🛠️ Especificaciones Técnicas

Backend - Modelos Django

Empresa - Raíz de multi-tenancy
├─ nombre, rut, email, teléfono, dirección
├─ estado (activo/inactivo)
└─ created_at, updated_at

Trabajador - Datos personales
├─ nombre_completo, rut, email, teléfono
├─ fecha_nacimiento, dirección
├─ estado (activo/inactivo)
└─ empresa_id (FK)

Contrato RRHH - Contrato laboral
├─ tipo (indefinido, plazo_fijo, temporal)
├─ trabajador_id (FK), empresa_id (FK)
├─ fecha_inicio, fecha_fin (nullable)
├─ estado (pendiente, vigente, finalizado, cancelado)
├─ salario_bruto, salario_liquido
├─ horas_semanales
├─ configuracion_previsional (JSON)
└─ archivo_firmado (nullable)

Configurable: 5+ modelos de apoyo (FondoPension, Bonificación, etc.)

Frontend - Componentes React

Páginas (8):
• ListadoEmpresas - Tabla con búsqueda/filtros
• DetalleEmpresa - Tabs: General | Configuración | Documentos
• ListadoTrabajadores - Grid de tarjetas con estado
• FichaTrabajador - Tabs: Información | Contratos | Documentos

Componentes Reutilizables:

State Management: Redux + RTK Query hooks

✅ Criterios de Aceptación

Crear Contrato Laboral

  • Flujo completo funcional
    Usuario puede completar todos los 7 pasos sin errores y guardar un contrato nuevo.
  • Validaciones frontend
    Campos obligatorios marcados, validación de RUT, fechas coherentes, cálculos de remuneración correctos.
  • Multi-tenancy funcionando
    Usuario solo ve/crea contratos de su empresa asignada.
  • Cambios persisten
    Contrato creado está visible en listado y detalle. Estado inicial es "pendiente".

Gestionar Contrato Existente

  • Búsqueda funciona
    Filtros por estado, rango de fechas, nombre trabajador retornan resultados correctos.
  • Edición parcial
    Usuario puede editar remuneración, jornada si contrato está en estado "pendiente".
  • Cambio de estado controlado
    Botón "Finalizar" solo disponible para contratos "vigente" o "pendiente firma".
  • Auditoría registrada
    Cada cambio deja huella con usuario, fecha, campo modificado.

Consultar Ficha Trabajador

  • Información consolidada
    Ficha muestra datos personales + todos los contratos activos/finalizados.
  • Documentos adjuntos
    Tab "Documentos" lista y permite descargar archivos asociados.
  • Historial visible
    Timeline de cambios en contratos con quién y cuándo.
