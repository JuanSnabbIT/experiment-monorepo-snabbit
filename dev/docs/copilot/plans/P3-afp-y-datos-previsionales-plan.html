P3 · AFP y datos previsionales

Convierte la AFP en un catálogo cerrado: UsuarioEmpresa.afp pasa de texto libre a FK a AfpCatalogo, se elimina isCreatable del selector, y se agrega tasa_cotizacion al catálogo para calcular descuentos (P6). El banco se mantiene libre por no ser un catálogo regulado.

Visión general
Catálogo cerrado de AFP + tasas de cotización
ℹ️
Por qué cuarto: el FK de AFP es prerequisito del pre-fill del wizard (ADR-11/P6) y del cálculo de descuentos con tasa_cotizacion (ADR-27). La validación de RUT de UsuarioEmpresa (ADR-13) se entrega en P4.

Decisiones incluidas

  • ADR-10 — AFP catálogo cerrado: quitar isCreatable; afp → FK AfpCatalogo. Banco sigue libre.
  • ADR-13 — Inconsistencias de UsuarioEmpresa: afp a FK (aquí); rut con validator (en P4).
  • ADR-27 — tasa_cotizacion: DecimalField en AfpCatalogo + seed de tasas vigentes.

def migrar_afp(apps, schema_editor):
    UsuarioEmpresa = apps.get_model("empresas", "UsuarioEmpresa")
    AfpCatalogo = apps.get_model("rrhh", "AfpCatalogo")

    catalogo = {a.nombre.strip().lower(): a.id for a in AfpCatalogo.objects.all()}
    sin_match = []

    for ue in UsuarioEmpresa.objects.exclude(afp_texto__isnull=True).iterator():
        clave = (ue.afp_texto or "").strip().lower()
        afp_id = catalogo.get(clave)
        if afp_id:
            ue.afp_id = afp_id
            ue.save(update_fields=["afp"])
        else:
            sin_match.append((ue.id, ue.afp_texto))  # SET NULL implícito

    if sin_match:
        print(f"[AFP] {len(sin_match)} registros sin match -> NULL: {sin_match[:20]}")
