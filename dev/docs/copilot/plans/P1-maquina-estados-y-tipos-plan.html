P1 · Máquina de estados y tipos de contrato

Define el contrato de datos base del ciclo de vida laboral: depura los tipos de contrato, normaliza la jornada, expande los motivos de término, reemplaza el booleano de gratificación por un enum, y separa el estado anulado en descartado + anulado. El frontend y todos los planes posteriores asumen este esquema definitivo.

Visión general
Refactor de choices y máquina de estados con data migrations
⚠️
Riesgo alto: cambios de choices sobre datos existentes. Requiere un script de verificación previo que detecte valores huérfanos (honorarios, obra_o_faena, part_time) antes de aplicar las migraciones.

Decisiones incluidas

  • ADR-01 — Eliminar honorarios de TIPO_CONTRATO (no es contrato laboral).
  • ADR-20 — Eliminar obra_o_faena (no aplica al perfil TI).
  • ADR-02 — Jornada: opciones fijas de horas [20,25,30,36,40,42,44]; eliminar part_time (→ parcial).
  • ADR-03 — Expandir MOTIVO_TERMINO_CONTRATO a 10 causales legales.
  • ADR-07 — gratificacion_legal: Boolean → tipo_gratificacion: CharField enum.
  • ADR-21 — Separar anulado → descartado + anulado; campo motivo_anulacion.

from django.db import migrations


def avanzar(apps, schema_editor):
    C = apps.get_model("rrhh", "ContratoTrabajador")
    # ADR-02: part_time -> parcial
    C.objects.filter(jornada="part_time").update(jornada="parcial")
    # ADR-01 / ADR-20: tipos eliminados -> indefinido (decisión admin en M1)
    C.objects.filter(tipo_contrato__in=["honorarios", "obra_o_faena"]).update(
        tipo_contrato="indefinido"
    )
    # ADR-07: bool -> enum (suposición conservadora)

        tipo_gratificacion="art_50_mensual"
    )
    C.objects.filter(gratificacion_legal=False).update(
        tipo_gratificacion="no_aplica"
    )

③ Gate de anulación en el ViewSet (ADR-21) — la salvaguarda no puede vivir solo en frontend.
backend/rrhh/views.pypython
@action(detail=True, methods=["post"])
def cambiar_estado(self, request, pk=None):
    contrato = self.get_object()
    nuevo = request.data.get("estado")

    if nuevo not in TRANSICIONES_CONTRATO.get(contrato.estado, []):
        return Response({"detail": "Transición no permitida."}, status=400)

    if contrato.estado == "vigente" and nuevo == "anulado":
        motivo = (request.data.get("motivo_anulacion") or "").strip()
        if not motivo:
            return Response(
                {"motivo_anulacion": "Requerido al anular un contrato vigente."},
                status=400,
            )
        contrato.motivo_anulacion = motivo

    contrato.estado = nuevo
    contrato.save()
    return Response(self.get_serializer(contrato).data)
