P2 · Campos legales del contrato

Completa los datos personales y legales exigidos por el Art. 10 del Código del Trabajo: estado civil, profesión, campos de reemplazo, especificación de sistema de salud y renombres semánticos de campos/tabs. Todos los campos son aditivos (null/blank), sin impacto en registros existentes.

Decisiones incluidas

  • ADR-04 — estado_civil + profesion_u_oficio (Art. 10 CT).
  • ADR-05 — Renombrar nombre→referencia_interna, lugar_firma→lugar_celebracion_contrato; tabs trabajador→datos_personales, sueldo→remuneraciones.
  • ADR-19 — Reemplazo: trabajador_reemplazado (FK) + causal_reemplazo, opcionales.
  • ADR-24 — Semántica de cargo documentada (sin cambio de schema).
  • ADR-25 — Labels/tooltips de fecha_inicio y fecha_contrato (solo verbose_name).
  • ADR-26 — sistema_salud_otro companion + validación condicional.

backend/rrhh/models.py · ContratoTrabajadorpython
ESTADO_CIVIL = (
    ("soltero_a", "Soltero/a"), ("casado_a", "Casado/a"),
    ("conviviente_civil", "Conviviente civil"),
    ("divorciado_a", "Divorciado/a"), ("viudo_a", "Viudo/a"),
)

# ADR-04 — datos personales (Art. 10 CT)
estado_civil = models.CharField(max_length=20, choices=ESTADO_CIVIL, blank=True, null=True)
profesion_u_oficio = models.CharField(max_length=150, blank=True, null=True)

# ADR-05 — renombrados (eran: nombre, lugar_firma)
referencia_interna = models.CharField(max_length=120, blank=True)
lugar_celebracion_contrato = models.CharField(max_length=120, blank=True)

# ADR-25 — solo verbose_name (sin migración de esquema)
fecha_inicio = models.DateField(verbose_name="Fecha de inicio de la relación laboral")
fecha_contrato = models.DateField(verbose_name="Fecha de firma del contrato")

# ADR-26 — companion de sistema_salud="otro"
sistema_salud_otro = models.CharField(max_length=100, blank=True,
    verbose_name="Especificar sistema de salud")

# ADR-19 — reemplazo (opcionales)
trabajador_reemplazado = models.ForeignKey("empresas.UsuarioEmpresa", null=True,
    blank=True, on_delete=models.SET_NULL, related_name="contratos_de_reemplazo")
causal_reemplazo = models.CharField(max_length=30, blank=True, choices=[
    ("licencia_medica", "Licencia médica"), ("vacaciones", "Vacaciones"),
    ("prenatal_postnatal", "Pre/postnatal"),
    ("permiso_sin_goce", "Permiso sin goce de sueldo"), ("otro", "Otro"),
])
② Validación condicional del companion de salud (ADR-26).
backend/rrhh/serializers.pypython
def validate(self, data):
    if data.get("sistema_salud") == "otro" and not (data.get("sistema_salud_otro") or "").strip():
        raise serializers.ValidationError(
            {"sistema_salud_otro": 'Debe especificar el sistema de salud cuando selecciona "Otro".'}
        )
    return data
