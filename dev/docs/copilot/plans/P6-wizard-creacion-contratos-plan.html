P6 · Wizard de creación de contratos

Refactor completo del wizard: desglose fijo de descuentos legales, gratificación como enum con cálculo del Art. 50, advertencia de IMM proporcional, pre-llenado de datos previsionales para trabajador existente, y modal de confirmación para la transición borrador → vigente. Acumula el resultado de P1–P5.

⚠️
El wizard ya está en producción. Riesgo de regresión en los flujos "nuevo trabajador" y "trabajador existente". Requiere pruebas end-to-end de ambos flujos antes del merge. Sin migraciones: los campos se crearon en P2 y P3.

Decisiones incluidas

  • ADR-06 — Reemplazar el selector libre de % por desglose fijo: AFP (tasa catálogo), Salud 7%, SC 0,6%. Preview = "estimación referencial".
  • ADR-07 (fe) — Mostrar gratificación como enum; calcular Art. 50: min(base×0.25, tope).
  • ADR-08 — Advertencia no bloqueante si base < IMM × horas/45.
  • ADR-11 — Pre-rellenar (no saltar) el step de previsión para trabajador existente; banner informativo.
  • ADR-22 — Modal de confirmación en borrador → vigente (salvaguarda frontend).

① Desglose de descuentos legales (ADR-06). Tasa AFP desde catálogo (P3).
frontend/src/pages/RRHH/components/trabajador/StepRemuneraciones.tsxtypescript
const TASA_SALUD = 0.07;       // 7% fijo por ley
const TASA_CESANTIA = 0.006;   // 0,6% aporte trabajador dependiente

function calcularDescuentos(base: number, tasaAfp: number | null) {
  const afp = tasaAfp != null ? Math.round(base * tasaAfp) : null;
  const salud = Math.round(base * TASA_SALUD);
  const cesantia = Math.round(base * TASA_CESANTIA);
  const totalDescuentos = (afp ?? 0) + salud + cesantia;
  return { afp, salud, cesantia, totalDescuentos };  // estimación referencial
}
② Gratificación Art. 50 (ADR-07) y advertencia IMM (ADR-08).
StepRemuneraciones.tsx · types.ts (P1)typescript
import { IMM_VIGENTE, IMM_TOPE_GRATIFICACION } from "./types";

// Art. 50: 25% del sueldo mensual con tope 4,75 IMM / 12
function gratificacionArt50(base: number): number {
  return Math.min(base * 0.25, IMM_TOPE_GRATIFICACION);
}

// ADR-08: advertencia NO bloqueante; divisor 45 (práctica DT)
function bajoImmProporcional(base: number, horas: number): boolean {
  if (!horas) return false;
  return base < (IMM_VIGENTE * horas) / 45;
}
