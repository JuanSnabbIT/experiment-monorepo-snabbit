Visión general
Qué resuelve este plan y por qué va primero
🛑
ADR-12 es un bug de seguridad activo. El get_queryset de contratos RRHH no filtra los contratos en modo "nuevo" (usuario_empresa=null). Un borrador creado por la empresa A es visible para la empresa B. Debe corregirse antes que cualquier otra cosa.

Objetivos

  • 🔒 ADR-12 — Cerrar la fuga de datos entre empresas en el queryset de contratos.
  • 🏷 ADR-15 — Renombrar estado pendiente_aceptacion → pendiente_aprobacion y fecha_aceptacion → fecha_aprobacion.
  • ✍️ ADR-23 — Corregir label 'Desactivo' → 'Inactivo' (sin cambiar el valor '2').

Implementación de referencia con resaltado de sintaxis
① Fix multi-tenancy — el corazón de ADR-12. El segundo término del Q evita la fuga sin romper el modo "nuevo".
backend/rrhh/views.pypython
from django.db.models import Q

class ContratoTrabajadorViewSet(viewsets.ModelViewSet):

    def get_queryset(self):
        user = self.request.user
        # IDs de empresas visibles para el usuario autenticado (multi-tenancy)
        ids_visibles = self._empresas_visibles(user)
        return ContratoTrabajador.objects.filter(
            Q(usuario_empresa__sucursal__empresa_id__in=ids_visibles)
            | Q(usuario_empresa__isnull=True, creado_por=user)
        ).distinct()
② Data migration del rename de estado (ADR-15). Reversible para permitir rollback seguro.
backend/rrhh/migrations/0001_rename_estado_contrato.pypython
from django.db import migrations


def avanzar(apps, schema_editor):
    Contrato = apps.get_model("rrhh", "ContratoTrabajador")
    Contrato.objects.filter(estado="pendiente_aceptacion").update(
        estado="pendiente_aprobacion"
    )


def revertir(apps, schema_editor):
    Contrato = apps.get_model("rrhh", "ContratoTrabajador")
    Contrato.objects.filter(estado="pendiente_aprobacion").update(
        estado="pendiente_aceptacion"
    )


class Migration(migrations.Migration):
    dependencies = [("rrhh", "0000_previa")]
    operations = [
        migrations.RenameField(
            model_name="contratotrabajador",
            old_name="fecha_aceptacion",
            new_name="fecha_aprobacion",
        ),
        migrations.RunPython(avanzar, revertir),
    ]
